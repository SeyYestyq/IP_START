# Визуальный язык и дизайн-система (референс для Copilot)

Документ фиксирует, **как выглядят и ощущаются** цифровые продукты, и как мы к ним прижимаем demo/production UI. Опирается на современные стандарты финтех-интерфейсов.

**Скриншоты актуального UI (2026):** [`references/web-2026/`](references/web-2026/) — разбор паттернов в [08-marketing-ui-patterns.md](08-marketing-ui-patterns.md).

## Официальные опоры стиля

| Элемент | Значение | Описание |
|---------|----------|----------|
| Фирменный красный | `#EF3124` (RGB 239, 49, 36) | Основной CTA-акцент |
| Платиновый | `#D1D5D8` | Вторичный цвет, плашки, разделители |
| Чёрный / белый | `#0B1117` / `#FFFFFF` | Контрастные пары и карточки |
| Слоган / тон | Прямой, уверенный, без канцелярита | Лаконичный диалог с предпринимателем |

## Дизайн-система в коде

Для **demo MVP**: визуально реализуем строгий финтех-стиль (красный акцент, воздух, типографика).

## Типографика продуктов

В интерфейсе используется чистый современный гротеск (Manrope, system-ui).

Характер интерфейса:

- легко и аккуратно;
- воздух и сбалансированный ритм;
- выразительные формы карточек;
- иконки согласованы со шрифтом в плотных таблицах, списках и формах.

**Demo:** Manrope / system-ui.

## Как устроен UI (паттерны)

1. **Shared shell** — верхнее меню, быстрый доступ к чату.  
2. **Контент на белых карточках-подложках** на нейтральном фоне `#F5F5F5`.  
3. **F-паттерн:** важные действия слева/сверху.  
4. Акценты витрин — из строгой палитры (красный / нейтрали), без лишнего неона.

### Что это значит для Copilot

| Зона | Поведение |
|------|-----------|
| Встраивание | Кнопка и раздел внутри кабинета рядом с чатом |
| Рабочая область | Белые поверхности, soft gray canvas `#F5F5F5` |
| Акцент CTA | `#EF3124` |
| Вторичный металл | `#D1D5D8` для dividers, chips, inactive |
| Copilot vs chrome | Воздух и чистота, надёжный финтех-стиль |

## Маркетинговый слой

Маркетинг использует пастельные тона, bento и 3D — это витринный слой.  
В продуктовом финансовом интерфейсе этот слой не доминирует (см. [01-design-system.md](01-design-system.md)).

## Чеклист визуального соответствия

- [ ] Красный `#EF3124` на primary CTA, не градиент purple→indigo  
- [ ] Платиновый / серый для вторички; pastel — на promo-карточках  
- [ ] UI-шрифт Manrope (или системный sans), 16px/150% в чате  
- [ ] Крупный radius 24–32px; pill segment с тёмным active  
- [ ] Canvas светло-серый + белые/pastel панели, воздух  
- [ ] Витрина: glossy 3D; money UI: спокойнее  
- [ ] Service rows + опциональная тёмная CTA-карточка  
- [ ] Суммы — tabular, крупная иерархия  
- [ ] Нет emoji как UI-иконок в денежных сценариях  
- [ ] Landing динамичнее (bento); `/app` — trust и паттерн «Сервисы»
